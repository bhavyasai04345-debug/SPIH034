# RiskRadar: AI‑Driven Predictive Safety System
“Protecting workers, assets, and the environment — proactively.”

##  Features
- Risk classification (Low/Medium/High)
- Explainable AI (SHAP/LIME)
- Recommendations (Inspect / Calibrate / Replace / Monitor)
- Prioritization engine for inspectors

##  Tech Stack
- **Python**: Pandas, Scikit‑Learn, TensorFlow
- **Backend**: Flask
- **Dashboard**: Streamlit
- **Database**: SQL/NoSQL
- **IoT (optional)**: MQTT / Edge devices
